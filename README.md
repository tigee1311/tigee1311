# Ayush Adi

I build practical AI and data products that turn messy real-world workflows into usable tools, with a focus on healthcare, research, sports analytics, and real-time decision systems.

## Featured Work

- **MedEase** - senior-friendly medication assistant with auth, prescription workflows, camera-based verification, caregiver alerts, Prisma/Postgres persistence, and a live Vercel deployment.
- **TruthLayer** - Chrome extension and FastAPI backend that adds real-time AI context to news articles with bias scoring, narrative comparison, voice summaries, and topic memory.
- **ColliderGuard** - CERN HIGGS anomaly-detection dashboard using Isolation Forest, Local Outlier Factor, One-Class SVM, PCA/t-SNE maps, and interpretable feature attribution.
- **Adaptive AI Physical Therapist** - webcam-based rehab coach using Claude plan generation, MediaPipe Pose tracking, real-time form feedback, voice cues, and fallback planning.
- **SDoHv4** - multilingual social determinants of health questionnaire with Streamlit, voice input/output, hospital-specific exports, persistent response storage, and research workflow notes.
- **OpsTwin AI** - warehouse digital-twin simulation with autonomous robot orchestration, WebSocket updates, SQLite state, pathfinding, congestion handling, and Gemini-powered planning.

## Stack

**Languages:** TypeScript, Python, JavaScript, SQL  
**Frontend:** Next.js, React, Vite, Tailwind CSS, Streamlit, Chrome Extensions  
**Backend:** FastAPI, Node.js, Express, Prisma, SQLite, PostgreSQL  
**AI/Data:** Claude, Gemini, MediaPipe Pose, scikit-learn, pandas, matplotlib, PCA, t-SNE  
**Deployment:** Vercel, Docker, Streamlit, GitHub Actions

## What I Like Building

I like projects where the AI or data layer has to do real work: analyze uncertainty, adapt to user input, explain decisions, or make a live workflow easier to understand. My strongest repos combine product thinking with practical engineering, not just isolated model demos.
